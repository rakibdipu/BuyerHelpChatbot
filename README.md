# BuyerBot — AI-Powered Buyer Help Chatbot

A smart, real-time buyer assistance chatbot built with **React + Vite**. Helps shoppers with product searches, order tracking, return policies, shipping info, and more.

## ✨ Features

- 💬 **Interactive Chat UI** — Clean, modern chat interface with bot/user bubbles
- 🔍 **Smart Search Results** — Context-aware product and price results with clickable links
- 📦 **Order Tracking Help** — Step-by-step guidance for tracking orders across all major retailers
- 🔄 **Return & Refund Policies** — Instant answers about Amazon, Walmart, Best Buy, and eBay policies
- 🚚 **Shipping Information** — Delivery time estimates and free shipping tips
- 💳 **Payment Assistance** — Help with payment issues and safe shopping tips
- ⚡ **Quick Actions** — One-click buttons for the most common buyer questions
- 🟢 **Typing & Searching Indicators** — Visual feedback while the bot processes responses

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ installed
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/BuyerHelpChatbot.git
cd BuyerHelpChatbot

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production

```bash
npm run build
npm run preview
```
